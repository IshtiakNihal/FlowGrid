## 9. Specify motion now; produce the video later

Motion is a core part of this design. It must be visible in the Figma specification and demonstrated where Figma can represent it. Do not mark it complete with only a sentence saying “add animations.”

Create a motion inventory with: interaction, purpose, trigger, start/end state, affected elements, duration/easing or scroll relationship, interruption/reversal, desktop/mobile behaviour and reduced-motion alternative.

| Interaction | Required design specification |
|---|---|
| Overview-to-apartment journey | Storyboard from accepted image IDs, route map, semantic room markers and explicit transition points |
| Scroll-controlled tour | Forward and reverse progress, start/end, skip/exit, loading poster, failure state and persistent route to enquiry |
| Header/menu | Legible open/closed states, focus behaviour and restrained transition |
| Project entry/detail | Clear click destination, image continuity where useful and back behaviour |
| Gallery | Selected image, previous/next, captions and keyboard/touch controls |
| Buttons and links | Immediate feedback without delaying navigation |
| Form | Focus, validation, submitting, success and failure states |
| Ordinary content reveal | A small number of deliberate entrances; content must remain available when motion is disabled |

Use approximately 150–250 ms for small feedback and 250–400 ms for larger UI transitions as starting values. The earlier 600 ms hero reveal and 360 ms project expansion are optional design candidates, not mandatory effects. Choose timing for the actual composition and document the decision.

The apartment tour is **scroll-linked**, not a fixed-duration hero animation. Define the intended progress relationship and room sequence. Do not promise that Figma proves continuous browser video seeking, media performance or reverse playback; those require the later footage and implementation.

Design normal scrolling outside the tour. Avoid forced scroll snapping, cursor tricks, endless pinning and essential content hidden behind hover. Reduced motion should provide readable stills and direct navigation without cinematic zooms. Mobile should have an intentional simplified option if the full sequence would be uncomfortable or lose key detail.

Create a separate motion-spec row for every proposed reference-inspired effect. Identify its reference and purpose. Do not reproduce an effect merely because a reference uses it.
