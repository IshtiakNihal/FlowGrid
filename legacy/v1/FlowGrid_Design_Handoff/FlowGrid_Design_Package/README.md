# FlowGrid design handoff

Version 1.0 - 26 September 2026

Start with FlowGrid_Design_System_and_References.pdf. The Markdown specification is the editable source of truth; the JSON file lists proposed tokens and computed solid-color contrast ratios.

References folder:
- 01_Desktop_Home.png: first three desktop homepage sections
- 02_Project_Detail.png: concept case-study page
- 03_Services_Enquiry.png: proposed services and enquiry pages
- 04_Mobile_Bangla.png: mobile Home, Projects and Enquiry

All interiors are generated design concepts, not completed FlowGrid projects. Wordmark and service categories are provisional. Images demonstrate visual direction; exact text, responsive sizes, states and behavior come from the specification.

Generation_Prompts.json preserves the prompts. The built-in image generator was used; a model version called 2.5 was not selectable or exposed. No website source code or deployment is included.

Source links and research limits appear in section 22 of the specification. The proposed business copy still needs owner approval; the proposed interface needs implementation and usability testing.
